# Tags OpenStreetMap utilisés

Le skill recherche les établissements sensibles en ciblant principalement les publics vulnérables (jeunes enfants, patients, personnes âgées).
Voici la liste des tags `amenity=*` recherchés :

- `school` : Écoles
- `kindergarten` : Écoles maternelles / Jardins d'enfants
- `childcare` : Crèches / Garderies
- `hospital` : Hôpitaux
- `clinic` : Cliniques
- `doctors` : Cabinets médicaux
- `pharmacy` : Pharmacies
- `nursing_home` : EHPAD / Maisons de retraite
- `social_facility` : Établissements d'action sociale
- `townhall` : Mairies (points de rassemblement potentiels)
- `fire_station` : Casernes de pompiers (secours)
- `police` : Commissariats / Gendarmeries
