# Limites des données

- **Mise à jour** : Bien que ce soit la base officielle, les mises à jour peuvent prendre quelques jours à quelques semaines. L'état exact d'une usine le jour de l'incident n'est pas garanti.
- **Périmètre** : La recherche se fait dans un rayon en mètres. Les coordonnées de l'usine peuvent être le point central (bureau, portail) et non l'installation dangereuse elle-même, qui peut s'étendre sur plusieurs hectares.
- **Utilisation** : Ce plugin ne peut en aucun cas remplacer les bases de données sécurisées ou les plans particuliers d'intervention (PPI) utilisés par les préfectures et les services de secours (SDIS, etc.).
