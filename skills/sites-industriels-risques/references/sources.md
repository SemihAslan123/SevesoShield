# Source des données ICPE / SEVESO

Ce skill utilise l'API Géorisques du gouvernement français.
**URL** : `https://georisques.gouv.fr/api/v1/installations_classees`

## Données disponibles
- **ICPE** : Installations Classées pour la Protection de l'Environnement.
- **Régime** : Autorisation, Enregistrement, Déclaration.
- **Statut Seveso** : Seuil haut, Seuil bas, ou vide (si non-Seveso).
- **État d'activité** : En fonctionnement, en cessation, etc.

C'est la source ouverte de référence en France pour ces installations.
