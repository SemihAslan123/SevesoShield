# Sources des données de population

Ce skill utilise l'API Découpage Administratif fournie par Etalab (geo.api.gouv.fr).
L'API moissonne et expose les données du Code Officiel Géographique (COG) de l'INSEE.

- **URL de base** : `https://geo.api.gouv.fr/communes`
- **Mise à jour** : Les données de population sont généralement celles du dernier recensement légal publié par l'INSEE.

## Pourquoi utiliser cette source ?
C'est une source ouverte, gratuite, sans clé d'API, maintenue par l'État français, très fiable pour croiser des coordonnées géographiques avec les limites administratives (département, région) et des données démographiques de base.
